# Mon Portfolio

Portfolio personnel développé afin de présenter mes projets, mes compétences et mon parcours dans le développement web.

L’application permet :
- la présentation de mes projets
- l’affichage dynamique des réalisations
- un formulaire de contact
- l’accès à mes réseaux professionnels

# Les Technologies Utilisées

- HTML5
- CSS3
- JavaScript
- Vue.js
- [Visual Studio Code](https://code.visualstudio.com/)
- [Vite](https://vitejs.dev/config/)
- Git & GitHub
- EmailJS

# Compétences développées

- Développement Frontend,

- Responsive design,
- Gestion des composants Vue.js,
- Navigation dynamique,
- Intégration d'un formulaire de contact,
- Structuration d'un portfolio web.

# Les Instructions d'installation

## Cloner le projet

```bash
git clone https://github.com/USERNAME/mon_portfolio.git
```

## Installer les dépendances

```bash
npm install
```

## Lancer le serveur

```bash
npm run dev
```
